## Rinse — before/after photos, ready to send

Built for Devpost **Build With AI: Basics** (October 2026).

A pressure-washing crew shoots a before, washes, shoots the after. Rinse pairs the photos on the phone, captions them, and gives the client one hosted link with a slider per area. No signal, no account, no API key required — the optional model only helps with the hard pairings and the wording.

`Vanilla JS · IndexedDB · service worker · Vercel + one serverless function`

[Live demo](https://rinse-weld-kappa.vercel.app/?demo=1) · [Code and docs](https://github.com/iYANSEN/rinse#readme) · [Scope](https://github.com/iYANSEN/rinse/blob/master/scope.md) · [PRD](https://github.com/iYANSEN/rinse/blob/master/prd.md) · [Spec](https://github.com/iYANSEN/rinse/blob/master/spec.md)
